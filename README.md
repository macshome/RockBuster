RockBuster
==========

A simple Asteroids-type game built with SpriteKit for macOS.

## Updated for 2024

This project has been modernized with:
- Updated deployment target to macOS 10.15
- Modern Objective-C property declarations
- Enhanced compiler warnings and build settings
- Updated copyright headers
- Performance optimizations for sound playback

## Requirements

- macOS 10.15 or later
- Xcode (compatible version for your macOS)

## Building

Open `Rock Buster.xcodeproj` in Xcode and build/run the project.

## Controls

- Press `1` on the title screen to start the game
- Arrow keys to control the ship
- Spacebar to fire missiles
- Backspace for hyperspace jump (when charged)
